Help

Something not working?

Here are the fixes for the usual problems.

Installing

My browser blocked the download

Some browsers are careful with new .exe files. Open your downloads (Ctrl + J), click the … or arrow next to the file, and choose Keep. If it asks again, choose Keep anyway.

There’s no “Run anyway” button

Click the small More info link first. The button only shows up after that. See step 2.

My antivirus flagged it

New games that aren’t code-signed sometimes get flagged by mistake. Check the file’s fingerprint. If it matches, it’s the real installer and you can allow it.

It says Pinkberry RNG is still running

Close the game first, then run the installer again. If it still complains, open Task Manager (Ctrl + Shift + Esc), end Pinkberry RNG, and try again.

Playing

The game won’t open, or the window is blank

Restart your PC and try once more. If it still won’t open, download the installer again and reinstall it over the top. Your save isn’t touched by reinstalling.

The game feels slow or laggy

Open Settings in the game and turn down the animation level, or turn off Background effects.

Where is my save?

In %APPDATA%\Pinkberry RNG\saves. Paste that into the address bar of File Explorer to open it. The game saves by itself and keeps backups.

How do I move my save to a new PC?
  1. On your old PC, open Settings in the game and click Export save.
  2. Copy that file to the new PC.
  3. Install the game on the new PC, then use Import save in Settings.

Other

Is it safe? What does it send online?

It’s safe. There’s no account and no tracking. It goes online for two things only: checking for updates, and the leaderboards.

The leaderboards show your profile name, avatar, title and stats. You can hide yourself on the Profile page in the game.

How do I uninstall it?

Open Windows Settings → Apps → Installed apps, find Pinkberry RNG, and click Uninstall. Your saves stay in %APPDATA%\Pinkberry RNG in case you come back. Delete that folder too if you want everything gone.

Does it work on Mac or phones?

Not right now. It’s Windows only.

Do I need to download it again for updates?

No. The game updates itself. See Updates.
