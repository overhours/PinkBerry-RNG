10 worlds

Each world has its own stuff, its own look, and weather that changes your luck.

Upgrades and pets

Spend hearts on luck and speed, hatch pets for bonuses, and rebirth for permanent perks.

Daily and weekly quests, secret quests, and lots of achievements to unlock.

Lola the bunny

How to install

  1. Click Download for Windows above.
  2. Open Pinkberry-RNG-Setup.exe from your downloads.
  3. Pick where to install it and click Install. That’s it. It adds a shortcut to your desktop and Start menu.
Seeing a blue “Windows protected your PC” box? That happens with games from small developers that haven’t paid for a code-signing certificate. Click More info, then Run anyway. If you want to double-check the file first, see “Is it safe?” below.

Questions

Is it safe?

Yes. The game doesn’t need an account, doesn’t collect anything about you, and doesn’t show ads. It only goes online to check for updates.

You can check your download matches the official one. Open PowerShell and run Get-FileHash $HOME\Downloads\Pinkberry-RNG-Setup.exe. The result should match this:

Shown on the latest release page.

How do updates work?

You only install once. When there’s an update, a flashing button shows up at the top of the game. Click it and the game updates itself and restarts. Your save is kept.

Where is my save?

On your computer, in %APPDATA%\Pinkberry RNG\saves. The game saves by itself and keeps backups. You can also export your save from Settings.

How do I uninstall it?

Go to Windows Settings → Apps → Installed apps, find Pinkberry RNG and click Uninstall.

Does it work on Mac or phones?

Not right now. It’s Windows only.
